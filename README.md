**Minecraft IP Bypass** — это удобное приложение для Windows, которое шифрует ваш IP-адрес, создавая скрытия вашего IP от серверов Minecraft.

> **Примечание**: Это инструмент для **ШИФРОВАНИЯ** вашего ip-адреса. Программа не предоставляет полный VPN или прокси сервер, но позволяет скрыть ваш реальный ip-адрес для minecraft.


## Установка

### Требования
- **Операционная система**: Windows 7, 8, 10 или 11.
- Никакого дополнительного ПО (например, Python) не требуется для запуска.

### Инструкции
1. Перейдите на вкладку [**Releases**]([https://github.com/yourusername/minecraft-ip-bypass/releases](https://github.com/riastag/Minecraft-IP-Bypass/releases/tag/minecraftipbypass)).
2. Скачайте последнюю версию `MinecraftIPBypass.zip`.
3. Разархивируйте папку из архива
4. Перейдите в папку `dist`
5. Запустите `MinecraftIPBypass.exe`, дважды щёлкнув по файлу.

> **Примечание**: Если антивирус блокирует EXE, добавьте его в исключения, так как это распространённая реакция на Revenge метод шифрования.

## Использование

1. **Запуск программы**:
   - После запуска вы увидите главное окно с вашим текущим IP-адресом.
2. **Смена IP**:
   - Введите пароль «admin» в поле «Пароль роутера» (Обычно этот пароль подходит ко всем роутерам с шансом **99%**.
   - Нажмите кнопку **Сменить IP**.
   - Следите за логами и прогресс-баром, пока программа подключается к роутеру и генерирует новый IP.
   - После завершения вы увидите новый IP-адрес.
3. **Сброс IP**:
   - Нажмите кнопку **Сбросить IP**, чтобы вернуть исходный IP.
   - Процесс сопровождается логами и прогресс-баром.
4. **Работа в трее**:
   - Сверните программу, чтобы она работала в фоновом режиме в системном трее.
   - Дважды щёлкните по иконке в трее или выберите «Показать» для восстановления окна.
   - Выберите «Выход» для закрытия программы (с возможным сбросом IP).
